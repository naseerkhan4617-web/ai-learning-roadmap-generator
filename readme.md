# 🚀 AI Learning Roadmap Generator

An AI-powered application that generates personalized learning roadmaps based on a user's skill level, available learning time, goals, and uploaded learning materials.

## ✨ Features

- 🤖 AI-powered learning roadmap generation
- 🎯 Multiple skill levels
  - Beginner
  - Intermediate
  - Advanced
  - Expert
- ⏳ Personalized timeline
- 📁 Upload PDF and TXT learning materials
- 📝 Customized learning goals
- 📥 Download generated roadmaps
- 🎨 Simple Streamlit user interface

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- Groq LLM
- python-dotenv
- PyPDF
